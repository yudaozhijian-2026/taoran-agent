# 0.27.9rc1：前端反馈完整性

同批50条真实复测发现：8条实时分析仅返回提示词占位句却标为成功；模型已生成的填写建议被旧specific=False条件过滤；空建议缺少明确依据。

- 实时提示词删除可照抄的输出示例。空白、仅标题或正文落在标签外属于内容/传输不完整，最多重新生成一次；失败尝试不发布到页面。保存受限权限的原始返回和提取正文，用于区分模型输出和解析问题。此检查不判断业务语义。
- 智能填写建议按模型实际返回的有效建议直接组装，涵盖完整性、客户类型、预约方式、目标、过程、评价和下一步。无需specific=False，不自动把“有建议”标为“不具体”，不改模型的具体性状态。
- 模型明确声明有建议、无需补充或需确认，并说明依据。缺少声明、声明与输出容器不一致，或声明无需补充但同时标记了待核对缺口，触发一次完整性补全。持续不完整时保留已生成分析，明确说明建议核对未完成，不冒充无需补充。
- 需确认事项可以与不同问题的填写建议并存，不强制重复或凑条数。证据features是可选观察信息，缺失不使完整意见失败。
- API传递建议状态与数量，另报content_complete，区别任务完成与内容完整。部分内容不可用仍可查看已有结果，并用原检测编号、原输入版本恢复；恢复和重复请求保留原访问权限及版本保护。
- 更新前端策略与意见缓存版本，避免新检测继续复用旧策略结果。保留历史任务及原始记录，不清空数据库。

验收包含366项Python测试、40项页面交互测试和真实浏览器场景，覆盖所有建议栏目、仅标题重生成、持续失败、空建议、需确认、语义观察不阻断、后台评分及回写保护。发布前使用原50条中的11条记录快照隔离复验真实模型，不向简道云写入，不视为全部50条回写复测。

发布只更新dsm-taoran-v2-agent。正式评分、40题、知识库与飞书服务保持原样。持续网络或模型故障无法保证即时完成，页面必须保留真实状态和恢复入口。
