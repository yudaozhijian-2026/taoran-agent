# 弹窗提示及用户自主重检

基于 5244fe8。取消所有弹窗提示中的检测编号和内部错误代码，失效链接、过期任务及失败状态提示返回拜访记录重新检测。直接打开失效链接返回中文提示页面。用户从表单再次发起检测时不再复用失败任务，保留旧失败审计；正在生成和已成功的任务继续复用。

增加常驻提醒：分析完成后，请点击“已读并返回”，可将 AI 最终反馈带回拜访记录填写页面。直接关闭弹窗不会同步反馈。

已完成但未显式返回的结果保留浏览器离开提醒；关闭不发送反馈，只有用户点击返回并取得有效结果后才交给简道云。外层叉号由简道云控制，常驻提醒不依赖关闭回调，不宣称能够拦截平台关闭按钮。

评分、语义观察、模型提示、知识库、访问权限与旧版本保护不变。只更新 TAORAN 服务。
