# 0.27.8rc1：分析与回写可靠性修正

基于第二轮50条测评和部署提交 a6dd08d 修正。原评分公式、语义仅观察、访问权限及旧版本回写保护保留。

- 原字段为空时允许 advice_basis.existing_content 为空；错误路径保留 advice_basis 和 existing_content，不再只显示 unknown。
- 最终意见的无建议情况允许空数组。未知/重复建议编号记录观察并由程序按输入顺序组装，不推断为达标。完整分析超过300字不因此失败；仍保留有界资源限制。
- 实时意见以安全纯文本显示；不因20～500字范围或尖括号而失败，允许完整纯文本无外层标记。真实截断、空输出仍不冒充成功。
- 格式错误最多定向重新生成一次，仍依据本次原文；保存失败候选、字段路径及耗时。语义观察不触发重生成。
- 实时分析不可用时最终意见独立完成并展示；Preview可用率仍单独统计。
- 分析结果在外部回写前持久保存，进程恢复可复用，不重复调用模型。网络/限流/服务临时故障最多3次回写尝试，每次重新校验来源版本，使用原事务编号。
- 回写后读取实际记录核对业务版本、评分与意见。服务确认记录编号不再单独作为成功依据。
- worker status保留兼容意义。新增workflow_status及formal_score；管理页展示分析失败、待回写、回写失败、旧版本或评分及反馈回写成功。模型不可用时formal_score为空，历史响应参考分仅审计。

验收：350项Python测试、39项页面交互测试、3项真实Chrome隔离场景；Ruff、Compose校验和Python构建通过。浏览器模拟外部故障，不向简道云写入。未重跑历史50条模型测评，不能将回归通过表述为真实模型100%成功。

外部边界：简道云读取与更新之间无已确认原子比较写入接口；写后复核能识别并报告并发变更，但不能承诺消除远端人工同时编辑的时间窗口。网络/模型长期故障仍进入可恢复状态，不生成虚假正式评分。
