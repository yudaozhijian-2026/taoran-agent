# TAORAN V1 正式发布

应用版本：1.0.0。发布标识：1.0.0-taoran-v1-20260909。

基于已验证提交 c82aa4843b18a5a27607e2a08845a61dda02f70e 正式定版；仅调整应用版本、健康接口发布名称和正式弹窗标题，分析、建议、评分、权限及回写逻辑保持不变。

包含异步任务、同版本复用、可恢复失败任务、中文最终反馈、缺失字段与原文歧义区分、局部格式修复、旧版本回写保护及飞书异常群通知。

基线验收：新增50条真实测评50/50技术检查通过；其中41、46条前端复测分别15.648秒、14.373秒，一次生成成功。历史测评结果不是V1重新执行的50条结果。

试点操作：输入或修改拜访记录，点击AI检测；等待AI最终反馈意见后点击已读并返回，再提交记录。实时分析完成不等于最终意见完成；关闭弹窗不会同步反馈。正式评分在提交后独立计算。生成或回写失败由既有飞书通知机制报告；不修改其他服务。

试点边界：技术链路检查不等同于所有业务判断绝对准确；模型服务仍可能出现慢响应。保留测试及业务历史数据，不自动清理缓存。

发布时须核对远端main和服务器提交，任务空闲且数据库完整后备份。回滚脚本位于 /TAORAN agent/backups/before-1.0.0-taoran-v1-20260909/rollback.sh；不自动覆盖发布后新增的业务数据库记录。完整镜像、提交与运行配置哈希由发布清单保存。
