## 兜底逻辑

只有以下条件同时满足时，才允许使用前端意见兜底：

1. 后端正式分析生成失败、异常或正式语义复核未完成；
2. 存在用户点击“确认提交”所激活的前端分析成果；
3. 前端成果的数据指纹与正式保存记录完全一致；
4. 前端成果包含已通过校验的完整用户可读意见。

执行时先读取简道云正式记录：

- “AI反馈意见”非空：判定提交前意见已经随表单保存，不发起任何回写；
- “AI反馈意见”为空：只写入前端AI意见；
- 无论哪种情况，均不写AI评分、Q33、Q34或其他正式评价字段；
- 回写使用`is_start_trigger=false`，避免兜底回写再次触发评价流程；
- 回写后重新读取并核对目标字段。

找不到前端成果、成果未确认、过期、损坏或与正式记录内容不一致时，不使用旧前端意见。
