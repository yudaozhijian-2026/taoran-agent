# 联系时间意见V3（1.0.5）

范围：仅后端AI意见口径、输出检查、回归及发布材料；评分引擎、Q33/Q34各50分、前端交互和响应配置不变。

目标客户跨北京时间自然月，潜力客户跨北京时间自然季度。商机客户意见不增加固定周期或日期先后要求；结合客户实际回应区分行动共识、时间约定和日期字段填写。评分内部日期条件仍按现行规则执行，不能照搬为商机客户意见。

## 商机客户事实边界

- 约定时间已明确但字段未填：补入真实时间，不重复确认已有共识。
- 行动已确认、时间未确定：只协商尚未确定的联系时间。
- 客户要求寄样、报价、提供方案：有相应行动回应，不等于约定了日期。
- 我方计划、内部批准、正在确认：不等于客户已确认。
- 条件式同意、拒绝、暂停：保留条件，不扩大成无条件同意。
- 交货、采购、内部会议日期：不自动等于联系日期。
- 十月后采购不表示十月前不能联系；承诺明天问财务不表示审批完成。
- 相对日期仅在原文和拜访日期可唯一确定时换算，多项安排分别判断。

N项和本次拜访分析口径一致；仅缺少日期不能单独否定行动内容的合理性。未填日期时不再强制覆盖为旧固定句。新增固定周期和变体样板句检查，命中后只按既有局部修复流程修复相关部分。
