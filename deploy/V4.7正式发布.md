# V4.7 正式发布约束

应用版本 `0.27.5rc2`，Git 标签和独立镜像标签 `0.27.5rc2-v47-20260907`。业务口径见根目录 `V4.7实施说明.md`。

本次从远端 main 的 `225e089529aaad616a3543ddc5f63c5e911810a3` 创建独立 worktree 和 `codex/formal-v47-20260907-e9a4` 分支。服务器当前 `0.27.5rc1-v47-20260907` 的源码功能在本次正式纳入 Git；其旧发布只有源码哈希，本次须同时记录 Git 提交。

验收顺序：Python 测试、浏览器测试、Ruff 检查、Compose 校验、构建。仅将 TAORAN 源码、测试、说明和部署文件提交推送并合入 main。构建使用锁定依赖及离线哈希验证，镜像 OCI revision 必须等于正式提交。

部署目录必须新建，不复用旧目录。发布材料包含 git-commit.txt、remote-main.txt、source-manifest.json、source-revision.txt、Compose、部署脚本和源码归档。部署前再次 fetch/ls-remote 确认 main 等于候选提交，读取服务器 current、版本、镜像 ID；若有变化先停止同步。

在服务器运行 `release_v47.py preflight`，确认前后台模型空闲、所有数据库任务（含持久弹窗任务）没有 queued/running/processing/pending，校验 SQLite 完整性，备份一致性数据库、实际 Compose、运行配置及旧镜像。`switch` 再次核对版本、数据和配置，且仅执行 TAORAN agent 的 `up -d --no-deps --pull never`。

`verify` 校验内外网健康接口、应用版本、镜像 Git 提交、已安装源码哈希、管理页面及静态资源、数据库表内容和任务队列、运行配置哈希、重启次数，以及其他所有容器（包括停止容器）的 ID、镜像、启动时间、状态和重启次数。通过后更新 current。

发布回执 `deployment.json` 和测试结果保存于发布目录及本地任务输出目录，不将真实客户记录、数据库、凭证、运行配置或生成的依赖包提交仓库。回滚脚本位于 `/TAORAN agent/backups/before-0.27.5rc2-v47-20260907/rollback.sh`，仅恢复 TAORAN 镜像及 current。数据库和配置另有一致性备份；应用回滚不覆盖上线后新增业务数据。
