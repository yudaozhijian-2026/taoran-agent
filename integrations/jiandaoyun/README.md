# 交互插件：关闭弹窗的兼容处理

前端扩展使用 `quick_check_interactive_frontend.js`。正式插件需保留自身的后端函数 ID，不能复制测试插件的 ID。

## 必须配置的输入

在前端扩展的请求参数中新增文本参数：

- 显示名称：当前AI反馈意见（关闭时保留）
- ID：`existing_feedback`
- 允许为空，多行文本，不勾选必填。
- 在表单前端事件中绑定当前表单的 **AI反馈意见** 字段。
- 返回参数 `resText` 仍绑定 AI反馈意见，不改变评分绑定。

新增参数仅供取消时原样返回，不进入分析数据、内容指纹或模型请求。不要在后端函数添加此参数。

## 行为

直接关闭是正常取消，不抛出插件执行错误；返回原意见值以保持页面内容不变。简道云实测中空对象会清空映射字段，而 undefined 会使按钮持续等待，因此不能用这两种返回方式实现取消。

仅“已读并返回修改”返回新意见。每次弹窗结束清理当前消息监听，旧弹窗消息不能影响新的弹窗。相同内容的缓存复用、不同内容的新分析仍由原服务处理。

修改插件参数后，必须重新保存表单事件映射，关闭事件设置面板，再保存整张表单。重新打开填写页面验证，旧页面不会自动载入新绑定。
